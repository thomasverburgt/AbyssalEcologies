Abyssal Ecologies 0.9.0

Requirements:
- Original Subnautica (2018), current non-Legacy desktop branch
- Tobey's BepInEx Pack for Subnautica
- Nautilus

Install:
1. Back up important saves and use a disposable test save. Schema-1 and schema-2 manifests migrate to canonical schema 3 without changing saved coordinates.
2. Merge the included BepInEx folder into the Subnautica game folder.
3. Launch the game once.
4. Load a disposable save; no layout is generated at the main menu.
5. Save once to persist `AbyssalEcologies.json` inside that save slot.
6. Check BepInEx/LogOutput.log for manifest status, region coordinates, and sampled prefab instances.
7. Run `ae_perf` after loading, after `goto ae1`, and after `goto ae2`. The initial budget must pass with 123 registered placements and nine content types; later reports expose cumulative callbacks and currently live custom objects.
8. Run `ae_boundaries 90` to draw non-colliding region rings and center markers for 90 seconds; use `ae_boundaries_off` to remove them early.
9. After visiting each region and waiting at least 12 seconds, run `ae_grounding`. Each central landmark should report `GROUNDED`. AE2 should create one collidable 132-metre-radius curved seamount, report 9/9 Glass Arch support hits, and surface-ground all 28 Prism Kelp. Move outside AE2 and return; the session-resident seamount must remain without duplication or floating flora. Confirm `ae_perf` still passes.
10. If grounding fails, run `ae_probe REGION` while that region is loaded. It reports bounded terrain-mask and all-layer raycast evidence without loading remote cells.
11. Run `goto ae2`, wait for Glassfin to stream, and run `ae_fauna`. Require the original-fauna prototype to be enabled and registered with at least one active instance. Inspect its cyan body, tail, side fins, facial filter fans, animation, and low-speed feeding display. Scan one to unlock the Glassfin databank entry, then run `ae_perf`.
12. Save, fully restart, revisit AE2, and repeat `ae_fauna` and `ae_perf`. If an Alien Containment Unit is available, also verify that a Glassfin egg is accepted and hatches. Set `Fauna.UseOriginalGlassfinPrototype=false` only when testing the Peeper-derived rollback visual.

The seed-58 lifecycle procedure above passed on 2026-09-26, including unload/revisit and a fresh-process recreation. The fresh-process run created exactly one seamount, grounded the Glass Arch with 9/9 hits, 0.10 metres of relief, and a 1.7-degree maximum support slope, and passed `ae_perf` at 18.3 ms setup, 6.1 ms registration, +0.89 MiB, and 123/123 placements.

Restart Subnautica before switching to a different save slot. Version 0.9.0 refuses to mix two per-save manifests in one running game process.

Disposable-save regeneration is deliberately restart-only. `ae_regenerate NEW_SEED CONFIRM_DISPOSABLE_SAVE_REGENERATION` first writes a timestamped byte-for-byte backup under `BepInEx/config/AbyssalEcologies/manifest-backups`, then stages the new deterministic layout in Subnautica's live save cache. The active world does not change until the game is saved, fully quit, and restarted. The command rejects missing confirmation, the active seed, and a second regeneration in the same process.

Temporary removal warning:
- Back up the save and fully quit before removing the two Abyssal Ecologies DLLs.
- A save can load temporarily without the mod, but Subnautica logs missing-prefab errors for saved custom instances.
- Do not save while the mod is missing. Quit and restore the exact DLLs before continuing.
- Permanent uninstall is not supported or validated in version 0.9.0.

Configuration is created at:
BepInEx/config/rocks.verburgt.subnautica.abyssalecologies.cfg

Existing save manifests keep their original seed even if the global configuration later changes.
