Abyssal Ecologies 0.7.0

Requirements:
- Original Subnautica (2018), current non-Legacy desktop branch
- Tobey's BepInEx Pack for Subnautica
- Nautilus

Install:
1. Back up important saves and use a disposable test save. Schema-1 and schema-2 manifests migrate to canonical schema 3 without changing saved coordinates.
2. Merge the included BepInEx folder into the Subnautica game folder.
3. Launch the game once.
4. Load a disposable save; no layout is generated at the main menu.
5. Save once to persist `AbyssalEcologies.json` inside that save slot.
6. Check BepInEx/LogOutput.log for manifest status, region coordinates, and sampled prefab instances.
7. Run `ae_perf` after loading, after `goto ae1`, and after `goto ae2`. The initial budget must pass with 123 registered placements and nine content types; later reports expose cumulative callbacks and currently live custom objects.
8. Run `ae_boundaries 90` to draw non-colliding region rings and center markers for 90 seconds; use `ae_boundaries_off` to remove them early.

Restart Subnautica before switching to a different save slot. Version 0.7.0 refuses to mix two per-save manifests in one running game process.

Disposable-save regeneration is deliberately restart-only. `ae_regenerate <new-seed> CONFIRM_DISPOSABLE_SAVE_REGENERATION` first writes a timestamped byte-for-byte backup beside the manifest, then stages the new deterministic layout. The active world does not change until Subnautica is fully restarted. The command rejects missing confirmation, the active seed, and a second regeneration in the same process.

Configuration is created at:
BepInEx/config/rocks.verburgt.subnautica.abyssalecologies.cfg

Existing save manifests keep their original seed even if the global configuration later changes.
